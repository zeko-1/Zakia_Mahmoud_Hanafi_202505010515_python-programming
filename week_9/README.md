# IT Helpdesk Ticket Registration System

## Purpose of the Application

This application is used to register IT helpdesk tickets for students who report technical problems such as LMS login issues, WiFi connection problems, printer malfunctions, and password reset requests.

## Tech Stack

* Python 3
* Modular programming
* Command Line Interface (CLI)

## How to Use

1. Run the `main.py` file.
2. Enter the student name, student ID, issue, location, and priority level.
3. The system will automatically assign a technician based on the priority:

   * High = Ahmad
   * Medium = Siti
   * Low = Ali
4. The completed helpdesk ticket will be displayed on the screen.
